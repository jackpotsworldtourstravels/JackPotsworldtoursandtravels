Component reference

Every variant, every state

Each specimen below is the real component from assets/template.css, not a picture of one. Tab through the page to check focus order; every interactive element shows a 2px ring at a 2px offset, which is a shape change rather than a colour change, so it survives greyscale and high-contrast modes.

The two golds are not interchangeable

brand.primary #D8B96A measures 1.9:1 against white and fails AA as text. It is a fill: button grounds and rules on black. Anything gold that carries a label on a light surface must use brand.ink #7A5F1E at 6.2:1.

Accessibility acceptance criteria

Each line below is testable on this page as it stands.

  • Tab reaches every interactive element in visual order
  • Arrow keys move between booking widget tabs; Home and End jump to the ends
  • Arrow keys move through autocomplete options, Enter takes one, Escape closes
  • Escape closes the mobile drawer and returns focus to the trigger
  • Focus is a 2px ring at 2px offset — a shape change, not colour alone
  • Every input has a visible <label>, never a placeholder standing in for one
  • Icon-only buttons carry an aria-label naming the action
  • Loading states set aria-busy and announce through a live region
  • Errors are tied to their field with aria-describedby and aria-invalid
  • Every touch target is at least 44×44px
  • Body, secondary and tertiary text all meet WCAG 2.2 AA on their own surface
  • All motion is suppressed under prefers-reduced-motion
