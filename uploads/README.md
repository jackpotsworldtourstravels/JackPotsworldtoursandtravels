# `uploads/`

Reserved for user-uploaded files. Empty — no file-upload feature exists
anywhere in the app yet (checked: no multipart/file endpoints in
`backend/app/routers/`, no `<input type="file">` wired to a real upload
call in any portal — the "Documents" section proposed for Merchant
Management in an earlier design pass was explicitly never built because
no backend support exists for it). This folder is provisioned ahead of
that feature, not evidence that it's implemented.
